لعبة السيك — مشروع Android Studio (نسخة 1.1)

التشغيل:
1) انسخ الملف إلى الحاسوب وفك الضغط.
2) Android Studio ← File ← Open ← اختر مجلد SeekGame ← Trust Project.
   (يُفضّل Android Studio Ladybug 2024.2.1 أو أحدث)
3) انتظر مزامنة Gradle (يحتاج إنترنت مرة واحدة فقط لتنزيل Gradle وأدوات البناء).
4) شغّل ▶ على المحاكي أو هاتفك (USB debugging).
5) لإنشاء APK: Build ← Build APK(s) ← app-debug.apk ثم ثبّته على الهاتف.

ما تغيّر في هذه النسخة:
- لا مكتبات خارجية إطلاقاً ولا إذن إنترنت؛ اللعبة تعمل دون اتصال بالكامل.
- إزالة خطوط Google Fonts (كانت تحتاج إنترنت) والاعتماد على خطوط النظام.
- اهتزاز حقيقي (navigator.vibrate لا يعمل داخل WebView).
- زر الرجوع: يغلق النوافذ ثم يسأل قبل الخروج.
- حفظ اللعبة تلقائياً واستئنافها عند فتح التطبيق.
- عدّاد انتصارات لكل فريق (مع زر تصفير في الإعدادات).
- إبقاء الشاشة مضيئة، تثبيت الوضع الرأسي، منع التكبير وتحديد النص.
- حماية من انهيار WebView ومنع الروابط الخارجية.

ملف اللعبة: app/src/main/assets/index.html
